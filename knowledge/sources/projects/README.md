# Local project source snapshots

NEXUS, ORBIT, and Beyond-Light were copied here at the user’s direction as source snapshots inside the shared Knowledge repository. These are project source collections, not the whole scope of the living shared graph. See each project’s `IMPORT_MANIFEST.json` for included-file hashes and exclusions.

The NEXUS signing keystore and its password properties are intentionally excluded from this public branch. Build caches, APK/AAB artifacts, and generated Gradle output are also excluded. ORBIT’s Python source, dataset, visualization, and experiment result files are included. Beyond-Light’s docs, app/source code, datasets, workflow files, tests, and source archive are included; Git history and generated build output are excluded.
