# Mnemos legacy source archive

Preserves the complete Python package as it existed at commit e90c271931f7519c02c700dee85b1710b7be021d, before consolidation.

These files are historical snapshots for migration and recovery. They are not intended to be imported by active runtime paths. Keep original function implementations and public contracts recoverable while consolidating the active implementation.

Original source files preserved: __init__.py, analysis.py, cli.py, contract.py, daemon.py, device_mapper.py, evolution.py, forensics.py, graph.py, integrity.py, live_graph.py, mcp_server.py, store.py.

This archive is a safety checkpoint, not a claim that runtime consolidation is complete.
